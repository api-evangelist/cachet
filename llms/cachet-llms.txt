# Cachet

> Cachet OÜ is an Estonian InsurTech providing adaptive, usage-based insurance for digital platforms in new mobility, gig work, and car-sharing. Platforms integrate via three inbound event APIs (Parking, Verify/Platform, Partners) authenticated with issued x-api-key + x-api-username headers.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public OpenAPI specifications and website. Cachet gates API access behind manual onboarding — contact devs@cachet.me.

## APIs

- [Cachet Parking API](https://docs.cachet.me/parking): Car-sharing fleets POST vehicle events (trip start/end, vehicle added) so Cachet manages parking. Base: https://platform-api.cachet.me
- [Cachet Verify / Platform API](https://docs.cachet.me/verify): Gig-work platforms register workers and push task events for worker protection. Base: https://platform-api.cachet.me
- [Cachet Partners API](https://docs.cachet.me/partners): Embed Cachet — POST customer/vehicle data to /connect and receive a prefilled onboarding redirect link. Base: https://partners.cachet.me

## Authentication

- Two required apiKey headers issued by the Cachet IT team: `x-api-key` and `x-api-username`.
- No OAuth, no scopes, no self-service key issuance.
